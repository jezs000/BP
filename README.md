Repozitář obsahuje kódy a soubory použité k vypracování bakalářské práce. 

Složka kódy obsahuje kódy použité k tvorbě trénovacích dat, trénování modelů a testování modelů.
Složka trénovací_data obsahuje vstupní datasety pro trénování modelů ve formátu JSON.
Složka vyýstupy_LLMs obsahuje výstupy z testování modelů del různých testovacích parametrů.
